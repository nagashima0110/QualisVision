# QualisVision

品質コンサルタント向け総合品質分析デスクトップツール

## モジュール構成

| モジュール | 状態 | 概要 |
|-----------|------|------|
| **QualisCoverage** | v0.1.0 | テストケースの組み合わせカバレッジ分析 |
| QualisBug | 準備中 | 不具合レポート分析・信頼性成長モデル |

## 必要な環境

- Node.js v18 以上

## セットアップ（初回のみ）

```bash
npm install
```

## 起動

```bash
npm start
```

## ビルド

```bash
# Windows
npm run build:win

# Mac
npm run build:mac

# 両方
npm run build:all
```

ビルド後のファイルは `dist/` に出力されます。

## QualisCoverage

テストケースの Excel / TSV ファイルを読み込み、以下の分析を行います。

- **組み合わせカバレッジ** — 2〜5因子間の網羅率
- **未カバー一覧** — テストされていない組み合わせの特定
- **値バランス分析** — 各因子の値の出現頻度・偏り
- **密度マップ** — 2因子間のテストケース密度ヒートマップ
- **重複ケース検出** — 同一条件の重複テストケース
- **因子値サマリー** — 各因子の値域一覧・表記ゆれ検出

### 対応ファイル形式

| 形式 | 拡張子 | 備考 |
|------|--------|------|
| Excel | `.xlsx` `.xls` | 結合セル自動補完 |
| TSV | `.tsv` `.txt` | Shift-JIS / UTF-8 自動判定 |

**Excel ファイルの構造**

- 1行目: 因子名（ヘッダー）
- 2行目以降: テストケース
- 「結果」「期待値」「備考」などの列は自動的に除外候補になります
